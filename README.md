# Personal Blog

This repository contains the source code for my personal blog.

It is where I publish notes, ideas, and writing on topics that interest me.

## Development

Use pnpm to install dependencies and run the site locally:

```bash
pnpm install
pnpm dev
```

The development server runs at `http://localhost:3000`. Use `pnpm build` to create a production build and `pnpm preview` to preview it locally.

## Deployment

The site deploys to GitHub Pages automatically whenever changes are pushed to `main`. In the repository’s GitHub settings, enable Pages and set the deployment source to **GitHub Actions**. You can also start a deployment manually from the **Actions** tab.
